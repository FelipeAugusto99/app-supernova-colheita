# Supernova Colheita - App Mobile

Global Solution 2026/2 (CitizenTech) - Mobile Application Development

Aplicativo em React Native (Expo) que conecta pequenos produtores da agricultura familiar a escolas, restaurantes e feiras, consumindo a API Java do projeto.

## Como rodar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Copie o `.env.example` para `.env` e coloque o endereço da API Java.
3. Inicie o projeto:
   ```bash
   npx expo start
   ```
4. Abra no Expo Go (celular) ou no emulador Android.
